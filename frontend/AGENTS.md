# AGENTS.md (frontend)

## 目录职责

本目录负责 Android 原生客户端（Kotlin + Jetpack Compose）：

- 登录注册。
- 家庭租户切换。
- 孩子切换与管理。
- 错题集列表与详情。
- 关注题列表与详情。
- 继续保留拍题入口作为错题来源。

## 技术约束

- 平台：Android 原生
- 语言：Kotlin
- UI：Jetpack Compose
- 网络：OkHttp
- 本地缓存：Room
- 后台任务：WorkManager

## 核心约定

- 家庭是租户边界。
- 当前孩子必须明确，并在设置页靠上位置切换。
- 错题页面只展示当前孩子的数据。
- 图片和附件只作为资产引用，不直接写死本地路径。
- 列表和详情页要支持后续多设备同步。
- 切换孩子后，任务列表、题集和题块集合操作都切换到当前孩子。

## 页面方向

- 主导航：拍题 / 题集 / 设置
- 拍题页左上角：任务列表入口
- 题集页：错题集 / 关注
- 设置页顶部：当前孩子与切换入口
- 错题详情页
- 关注题详情页

## 账号页面

- 登录页只显示用户名和密码。
- 注册页只显示用户名和密码。
- 不在前端收集手机号、邮箱、验证码、家长姓名或家庭名称。
- 注册成功后使用后端返回的 token、用户和家庭信息保存会话。

## 题块操作

- 解析结果题块卡片上提供两个按钮：错题、关注。
- 错题按钮支持加入 / 移出。
- 关注按钮支持关注 / 取消关注。
- 题目切图本阶段只消费后端预留字段，不做前端裁剪交互。

## 本地缓存

- 可以缓存最近查看的错题和孩子选择。
- 不能把本地缓存作为主数据源。
